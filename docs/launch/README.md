# Launch

Copy for the two places this is meant to be announced, and what has to be true
before either of them works.

| File | For |
| --- | --- |
| `show-hn.md` | Hacker News, as `Show HN:`, with the repository as the link |
| `product-hunt.md` | Product Hunt, as a listing with a gallery |

The pictures both files refer to are in `docs/screenshots/`, taken from the demo
desktop so that no real host appears in them.

## What is true now, and what is not

Done:

- The repository is public: <https://github.com/adfnekc/ad_explorer>
- v0.1.0 is tagged and released, with a static Linux binary and a checksum.
- GPL-3.0, because it links grdp, which is.
- English by default, Chinese from the title bar.
- `-demo` runs without a Windows machine, which is what makes a link worth
  clicking for someone who does not have one to hand.

Not done, and it matters for both posts:

- **A recording.** A drag staying smooth is the whole claim, and a still picture
  cannot make it. Thirty seconds of dragging a window, with the readout visible,
  is worth more than the rest of the copy.
- **A second machine.** Neither post is honest until it has been installed and
  run somewhere that is not the machine it was built on.
- **A real Windows screenshot**, if one can be had: the demo desktop is honest
  but it is a demo, and the first reaction to a remote-desktop post is "show me
  a real one".

## The known fault, and how to talk about it

Fast motion still produces the occasional torn frame. Both drafts say so
explicitly. That is deliberate: the alternative is a thread where someone finds
it and the answer reads like a cover-up, and this crowd finds everything.
